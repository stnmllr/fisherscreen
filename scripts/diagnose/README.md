# Diagnose-Skripte (historisch)

Explorative Einweg-Werkzeuge aus der Entwicklung — ursprünglich Tier A (Tool A),
seit 2026-09 auch Tool-B-Forensik. Historisches Material, nicht für produktive
Nutzung. Variants (v1–v4) dokumentieren iteratives Debugging.

Wiederverwendbare Instrumente gehören **nicht** hierher, sondern eine Ebene höher
nach `scripts/` — dieses Verzeichnis ist bewusst der Ablageort für Skripte, die
ihre Frage bereits beantwortet haben.
